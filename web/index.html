About

Datum

Datum is the browser client included with CityJSON MCP. It connects an LLM model to 37 MCP actions.

The actions cover metadata and object inspection, attribute and spatial queries, schema validation, geometry validation with, subsetting, reprojection, cleanup, triangulation, merging, from and to CityGML conversion, OBJ/STL/GLB/B3DM export, and cjdb/PostGIS import and export.

CityJSON MCP is an open source project developed by Yarroudh. The source code, setup documentation, issue tracker, and contribution instructions are available in the GitHub repository.
